# Contributing

## Adding an entry

1. Confirm it's an actual geospatial-relevant MCP server.
2. Add it to the most specific matching category; propose a new category only with 3+ entries.
3. Format: `- [Name](url)`. Neutral, no marketing language; link to the source repo or primary docs.
4. Keep entries alphabetical within their category.
5. Open a PR titled like `Add [Server Name]`.

## Removing / flagging an entry

If a project is archived, 404s, or was superseded, open a PR removing it or updating the link, and say why in the PR description.

## Style

- One entry per maintainer per PR unless it's a batch cleanup.
- Descriptions should tell someone whether to click, not just restate the name.
